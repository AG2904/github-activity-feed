# Código de conducta

## El compromiso

Este es un proyecto personal, abierto a quien quiera usarlo, leerlo o discutirlo.
Cualquiera puede abrir un issue, comentar o mandar un pull request sin importar su
experiencia, su idioma materno, su identidad ni su forma de trabajar.

## Qué se espera

- Discutir ideas, no personas. Un pull request se rechaza por lo que hace al código,
  y el motivo se escribe.
- Asumir buena fe: quien pregunta algo que ya está en la documentación no lo hizo
  para hacerte perder el tiempo.
- Aceptar un "no" con su razón. Un proyecto personal elige su alcance, y esa elección
  se explica una vez; no se negocia con insistencia.

## Qué no se acepta

- Insultos, acoso, ataques personales o comentarios despectivos sobre una persona o un
  grupo.
- Publicar información privada de otra persona sin su permiso.
- Insistir después de un "no" explícito, o reabrir la misma discusión para desgastar a
  quien ya la cerró.

## Alcance

Aplica a los issues, los pull requests, los comentarios y cualquier espacio del
repositorio donde alguien hable en nombre del proyecto.

## Cómo reportar un incidente

El repositorio no tiene un canal privado de moderación. Si el incidente no puede
hacerse público, se reporta por el reporte privado de vulnerabilidades de GitHub
(Security → Report a vulnerability); si puede, alcanza con abrir un issue. El
mantenedor lee, responde y decide. Si el reporte involucra a quien mantiene el
proyecto, se dice y se busca una salida.

## Atribución

Está inspirado en el [Contributor Covenant](https://www.contributor-covenant.org/),
versión 2.1, recortado a lo que un proyecto de una sola persona puede sostener.
